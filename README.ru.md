# Проверка Telegram-ссылок и каталог сообществ

Проверяет, что открывается по публичной Telegram-ссылке. В каталоге — небольшие тематические подборки с датой проверки.

[Открыть подборки](README.md#community-directory) · [JSON](data/communities.json) · [Отчёт проверки](reports/directory-checks.json)

Telegram может вернуть **200 OK** для обычной страницы контакта. Такой ответ ещё не подтверждает, что ссылка открывает указанный в подборке чат или канал.

Проверщик читает публичное превью. Достаточно Python 3.10+; аккаунт Telegram, токен бота и ключ API не нужны.

```bash
git clone https://github.com/JustJuice55/telegram-link-checker.git
cd telegram-link-checker
python3 telegram_link_checker.py --file path/to/README.md \
  --json report.json --markdown report.md
```

Результаты:

- `community_preview` — в публичном превью есть число участников или подписчиков.
- `contact_only` — обычная страница контакта; публичного сообщества в превью не видно. Ссылку и её описание стоит проверить.
- `bot_preview` — страница предлагает запустить бота.
- `inconclusive` — сеть, проверка доступа или незнакомая разметка помешали проверке.

`contact_only` не означает удаление или бан. Превью с участниками не доказывает активность обсуждения, качество аудитории или безопасность группы. Проверщик ничего не удаляет из исходного файла.

В первом выпуске: работа в России и Турции, образование в Узбекистане. У каждой записи есть прямая ссылка в Telegram и карточка [TGDen](https://tgden.com/ru/chats?utm_source=github&utm_medium=open_data&utm_campaign=telegram_community_map). Страна и тема взяты из фильтров каталога и могут требовать уточнения.

Подборка обновляется ежедневным заданием GitHub. При сетевой ошибке или неопределённом результате сохраняется прежний опубликованный снимок. [Инструкция по подключению проверки к своему репозиторию](README.md#check-a-list-in-github-actions).
